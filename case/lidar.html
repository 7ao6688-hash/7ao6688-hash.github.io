LiDAR forest inventory · New Forest, UK

Turning LiDAR into a forest inventory

Airborne laser scanning measures the height of every tree from above. This project turns LiDAR elevation models into canopy height, stand statistics and a ranked list of the forest areas that most need checking on the ground.

The question

Forest managers need to know how tall and how dense the trees are, compartment by compartment, to plan thinning, protect habitats and estimate timber or carbon. Measuring every stand on foot is slow, while LiDARLight detection and ranging: an aircraft fires laser pulses and times their return, mapping the ground and tree tops in 3D. covers a whole forest in one flight.

What I did

  1. Separated ground from vegetation in the laser returns and built a bare-earth model (DTM) and a surface model (DSM).
  2. Calculated canopy height (CHMCanopy height model: the height of the vegetation above the ground, from surface height (DSM) minus ground height (DTM).) as surface minus ground, with negative values set to zero.
  3. Summarised each forest compartment: canopy cover, the share of trees in each height class, and the 95th-percentile height, which ignores stray tall pixels.
  4. Tested how stable the results are if the elevation models are off by a few tens of centimetres, or if the height thresholds change.
  5. Ranked compartments for field checks with a transparent score, so foresters know where to look first.

What it produces

In the original research project I applied this to 15 compartments of the New Forest, combining LiDAR with airborne multispectral imagery to classify the canopy. The public version rebuilds the workflow as tested, reusable code. Because the original survey data are licensed, it ships with a synthetic scene with the same structure, so anyone can run it and see the outputs.

The ranking is a list of where to send field teams first. It doesn't decide where to harvest. In a protected landscape like the New Forest, that decision also depends on habitats, access and permissions.

How sure can we be?

  • The public results are a demonstration, not field measurements.
  • Vertical errors in the elevation models shift every height. The workflow reports how the rankings change when they do.
  • Height isn't species. Multispectral or field data are needed to tell conifers from broadleaves.

What a client gets

  • Canopy height and cover maps
  • A compartment table with height classes and P95 height
  • A prioritised list for field validation
  • A data guide for preparing your own LiDAR (LAS/LAZ or GeoTIFF) in PDAL, QGIS or ArcGIS
